# 🚀 SysMemClean

**SysMemClean** is a lightweight, background Windows utility designed to optimize system RAM and purge Standby Lists without causing in-game lag or frame drops.

---

### ✨ Key Features
- 🎮 **Anti-Stuttering Protection:** Automatically detects your active game or app in the foreground and keeps its working memory safe from purges.
- ⚡ **Smart Memory Recovery:** Purges Windows Standby Lists and background working sets to instantly free up gigabytes of RAM.
- ⚙️ **Seamless Auto-Start:** Integrated with Windows Task Scheduler to run at startup with elevated privileges without annoying UAC prompts.
- 📊 **Custom Thresholds & Intervals:** Set your preferred RAM usage percentage trigger and check frequency.

### 🔧 System Requirements
- **OS:** Windows 10 / 11 (64-bit)
- **Privileges:** Administrator Rights (required for Windows native memory API calls)

---

### 🛠️ How to Use
1. Download `sysmemclean.7z` and and unzip it on a folder
2. Right-click on `sysmemclean.exe` and **Run as Administrator**.
3. Check start with Windows to enable background auto-start.
4. Minimize to system tray — it will run quietly in the background!
